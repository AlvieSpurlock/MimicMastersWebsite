# Add the Mimic Masters site here

This folder already holds the files I changed or added for Mimic Masters:
the new **Transparency** page, the Charity menu in the nav, the Made / Given / Kept
trackers, and the CSV hookup in `assets/donations.js` and `assets/config.js`.

1. Copy everything from your MimicMastersWebsite repo into this folder,
   **except** the `.git` and `.github` folders. The privacy-sync bot already
   lives at the root of this project in `.github/workflows/sync-privacy.yml`.
2. When Windows asks about files that already exist, choose
   **"Skip these files."** That keeps the updated versions that are already here.
3. Delete this file once you're done.

After that, `mimic-masters/` is a complete copy of the site with the transparency
features included, and every link from the main site (screenshots, store badges,
"Visit the Website", the Transparency page) will work.
